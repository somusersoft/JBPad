# CreateInstall --- проекты установщиков для Windows

В этом каталоге находятся проекты CreateInstall для создания
установщиков JBPad под Windows, а также исходные файлы, используемые при
их сборке.

Установщики --- необязательный способ распространения JBPad для
пользователей Windows. Сама программа является portable-приложением и не
требует установки.

**Инструмент для создания установщиков:** CreateInstall Free 8.11.2\
**Скачать:** https://www.createinstall.com/download-free-trial.html

## Возможности установщика

Проекты реализуют простую схему установки настольного приложения:

1. Выбор языка.
2. Выбор каталога установки.
3. Завершение установки с возможностью сразу запустить программу.

Установщик распаковывает файлы приложения в выбранный каталог и создаёт
ярлык на рабочем столе. Запись данных в реестр Windows не используется.

Деинсталлятор находится в каталоге установленной программы. Поведение
при удалении каталога `Data/` описано в разделе [«Удаление программы и
пользовательские
данные»](#удаление-программы-и-пользовательские-данные).

## Сборка установщиков JBPad

Установите CreateInstall Free 8.11.2, затем выполните следующие
действия:

1. Откройте файл проекта для нужной архитектуры:
   - `installer_JBpad32.ci` --- для 32-разрядной сборки Windows;
   - `installer_JBpad64.ci` --- для 64-разрядной сборки Windows.
2. Нажмите **«Создать установку»**.
3. Дождитесь окончания сборки.

Готовый установщик появится в каталоге `build/`.

В проектах используются относительные пути, поэтому они не привязаны к
конкретному абсолютному пути на компьютере разработчика.

## Адаптация проектов для другой программы

Эти проекты можно использовать как основу для создания установщика
другой настольной программы для Windows. Для этого потребуется заменить
файлы JBPad и изменить настройки проекта.

Ниже в качестве примера используется условное название программы
`MyApp`. Названия и расположение некоторых параметров могут различаться
в зависимости от языка интерфейса или версии CreateInstall.

### 1. Подготовка файлов

1. Скопируйте весь каталог `CreateInstall` в удобное место.
2. Удалите файлы JBPad из каталога `source/` и поместите туда файлы,
   необходимые для установки вашей программы. В зависимости от
   приложения это могут быть:
   - исполняемый файл;
   - дополнительные каталоги и ресурсы приложения;
   - файлы настроек;
   - иконка приложения в формате `.ico`;
   - файлы лицензий и уведомлений о сторонних компонентах, если они
     необходимы.
3. Создайте отдельную иконку установщика и поместите её в корневой
   каталог скопированного проекта `CreateInstall`.

Иконка установщика используется в мастере установки и отображается в
Проводнике Windows у файла установщика. Согласно документации
CreateInstall, её размер не должен превышать 64 × 64 пикселя.
Рекомендуется создать файл `.ico`, содержащий изображения размером 16 ×
16, 24 × 24, 48 × 48 и 64 × 64 пикселя.

Иконка приложения и иконка установщика выполняют разные функции: первая
может использоваться для ярлыка на рабочем столе, вторая обозначает сам
установочный файл.

### 2. Настройка проекта

Откройте соответствующий файл проекта `.ci` в CreateInstall.

Замените значения, относящиеся к JBPad, на значения для своей программы.

#### Вкладка «Проект» --- пункт «Вывод»

Измените имя создаваемого установочного файла.

Например:

`JBPad_1.0_Windows7+_x32_setup.exe` → `MyApp_setup.exe`

#### Вкладка «Проект» --- пункт «Информация о программе»

Измените отображаемое название программы.

Например:

`JBPad 1.0` → `MyApp`

#### Вкладка «Проект» --- пункт «Установки»

Измените путь установки по умолчанию.

Например:

`#userpath#\JBPad_Windows7+_x32` → `#userpath#\folder_for_MyApp`

В CreateInstall глобальная переменная `#userpath#` обозначает
пользовательский путь. В документации он указан как
`C:\Users\Пользователь\`, где вместо слова «Пользователь» используется
имя учётной записи Windows. В приведённом примере программа будет
установлена в отдельный каталог `folder_for_MyApp` внутри этого пути.

### 3. Настройка сценария установки

Перейдите на вкладку **«Скрипт установки»**. Описанные ниже параметры
находятся в дереве в центральной части окна, под корневым пунктом
«Установка».

#### Пункт «Установка» --- параметр «Файл иконки»

Укажите иконку установщика, подготовленную на предыдущем этапе.

Например:

`$prjpath$\JBPad_setup.ico` → `$prjpath$\MyApp_setup.ico`

В этом примере предполагается, что файл `MyApp_setup.ico` находится в
корневом каталоге проекта `CreateInstall`.

#### Пункт «Проверка требований»

Выберите самую раннюю версию Windows, на которой поддерживается ваша
программа. При необходимости измените текст сообщения об ошибке.

Если установщик будет запущен на неподдерживаемой версии Windows,
появится сообщение, после чего установка будет прервана.

#### Пункт «Диалог --- Путь установки» --- параметр «Добавлять папку при выборе»

Измените значение на имя каталога вашей программы.

Например:

`JBPad_Windows7+_x32` → `folder_for_MyApp`

Если пользователь выберет `C:\` в качестве базового пути, установщик
добавит к нему имя каталога и предложит путь `C:\folder_for_MyApp`.

#### Пункт «Установочные файлы»

Удалите записи о файлах JBPad и добавьте файлы своей программы из
каталога `source/`.

Рекомендуется использовать относительные пути через переменную
`$prjpath$`. Это упрощает перенос проекта на другой компьютер или в
другой каталог без необходимости вручную исправлять каждый путь.

Например, абсолютный путь:

`D:\Temp\CreateInstall\source\MyApp.ico`

можно записать так:

`$prjpath$\source\MyApp.ico`

В этом примере каталог `source/` находится непосредственно внутри
каталога проекта.

#### Пункт «Ярлык --- Создать»

Измените параметры ярлыка на рабочем столе. Например:

- **Имя ярлыка:** `JBPad_x32` → `MyApp`
- **Имя файла:** `JBPad_x32.exe` → `MyApp.exe`
- **Файл иконки:** `JBPad.ico` → `MyApp.ico`

Укажите реальные имена файлов, которые будут установлены. Иконка ярлыка
должна ссылаться на `.ico` вашей программы.

#### Пункт «Запустить приложение»

Измените имя исполняемого файла на имя файла установленной программы.

Например:

`JBPad_x32.exe` → `MyApp.exe`

Здесь должен быть указан исполняемый файл приложения, а не установщик.

### 4. Создание и проверка установщика

Проверьте, что все указанные файлы существуют, а пути ведут к правильным
каталогам.

Нажмите **«Создать установку»** и дождитесь окончания сборки. Готовый
установщик появится в каталоге `build/`.

## Удаление программы и пользовательские данные

Каталог `Data/` содержит файлы локализаций, темы, файлы справки и
пользовательские блокноты.

При удалении программы деинсталлятор удаляет файлы приложения и ярлык на
рабочем столе. Если пользователь не создавал собственных файлов в
`Data/`, деинсталлятор удаляет каталог `Data/` и каталог программы
целиком.

Если пользователь создал хотя бы один собственный файл в `Data/`,
деинсталлятор удаляет остальные файлы приложения, но сохраняет
пользовательские файлы и каталог `Data/`, в котором они находятся. Таким
образом, после удаления программы в оставшемся каталоге должны
находиться пользовательские данные, а не встроенные файлы локализаций,
тем или справки.

Такое поведение предусмотрено для защиты пользовательских блокнотов от
случайной потери. После удаления программы проверьте оставшийся каталог
`Data/` и скопируйте нужные файлы в безопасное место, прежде чем вручную
удалять его.
