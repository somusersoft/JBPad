# JBPad 1.0

JBPad — бесплатный кроссплатформенный текстовый редактор с открытым исходным кодом. Написан на Python и PyQt5, работает без установки.

## Возможности

- Организация записей в виде дерева и редактирование текста во вкладках.
- Многоязычный интерфейс.
- Встроенный редактор локализаций.
- Редактор тем с 52 настраиваемыми параметрами.
- Хранение данных приложения в формате JSON.
- Ссылки на веб-ресурсы в дереве.
- Переносимое хранение данных рядом с приложением.

## Портативность и хранение данных

Программа является полностью портативной (portable), не требует установки и работает прямо из папки.

- `JBPad.py` — основной файл исходного кода приложения.
- `Setting.ini` — файл настроек приложения.
- `Data/` — данные приложения: локализации, темы, справочные блокноты и блокноты пользователя.
- `resources/` — ресурсы приложения (значки и курсоры).
- `*.spec` — конфигурационные файлы PyInstaller для сборки под разные платформы.
- `packaging/Windows/CreateInstall/` — необязательный проект установщика для Windows.

JBPad не требует установки и не использует системные каталоги для хранения настроек и пользовательских данных. Настройки и данные приложения хранятся в каталоге самой программы.

Программа изначально проектировалась для запуска со съёмных носителей (флешек). В конфигурации All_OS на накопителе с файловой системой exFAT вы можете работать с одной и той же копией данных, легко переключаясь между системами: Windows 7+, Windows 10+, Linux и macOS.

В комплект JBPad входят справочные блокноты на русском и английском языках. При первом запуске программа автоматически открывает блокнот, соответствующий выбранному языку интерфейса. Эти блокноты знакомят пользователя с возможностями редактора и доступны для редактирования наравне с обычными блокнотами. Если файлы справки отсутствуют, программа запускается без открытых блокнотов, и пользователь может создать первый блокнот самостоятельно. При последующих запусках программа открывает последний использовавшийся блокнот.

## Сборка из исходного кода

Файлы спецификаций PyInstaller находятся непосредственно в корне репозитория:

- `JBPad_Windows7.spec`
- `JBPad_Windows10.spec`
- `JBPad_Linux.spec`
- `JBPad_Linux_onefile.spec`
- `JBPad_macOS.spec`
- `JBPad_macOS_onefile.spec`

Используйте спецификацию, соответствующую целевой операционной системе и конфигурации сборки. Перед сборкой ознакомьтесь с инструкциями. Команды сборки следует выполнять из корневого каталога репозитория в окружении, настроенном для целевой платформы.

Файлы `*_onefile.spec` предназначены для сборки приложения в режиме `onefile`. В случае macOS результатом является пакет приложения `.app`. Эти сборки используются исключительно как компоненты для создания единой конфигурации All_OS.
